Everything that happens before the first line of code. Todo lo que pasa antes de la primera línea de código.

project-kit works with your AI agent to define the project, decide the stack, agree how the team works and plan the backlog. Then it sets up GitHub and hands over to Spec Kit. project-kit trabaja con tu agente de IA para definir el proyecto, decidir la pila, acordar cómo trabaja el equipo y planificar el backlog. Después prepara GitHub y se lo entrega a Spec Kit.

From an idea to issues, one phase at a time.De una idea a las issues, fase a fase.

Each phase is a skill your agent runs: one question at a time, a recommended answer for each, everything written to files in your repository. You sign off each phase before the next one starts.Cada fase es una skill que ejecuta tu agente: una pregunta cada vez, una respuesta recomendada para cada una y todo escrito en ficheros de tu repositorio. Tú apruebas cada fase antes de que empiece la siguiente.

Small project? Quick mode skips three phases.¿Proyecto pequeño? El modo rápido se salta tres fases.

After the handoff, Spec Kit takes over: each issue is one spec. Tras la entrega trabaja Spec Kit: cada issue es una especificación. /speckit-specify → plan → tasks → implement

Three steps, then just say “continue”.Tres pasos y después solo «continúa».

You can stop after any phase and come back another day. pjkit status always says where you are.Puedes parar después de cualquier fase y volver otro día. pjkit status siempre dice dónde estás.

1

InstallInstala

uv tool install project-kit-cli
uv tool update-shell
pjkit doctor

Install it as a tool, not inside a project's environment: the skills call pjkit by name. For GitHub you need gh with the repo and project scopes.Instálalo como herramienta, no dentro del entorno de un proyecto: las skills llaman a pjkit por su nombre. Para GitHub necesitas gh con los scopes repo y project.

2

Initialise the repositoryInicializa el repositorio

cd my-project
pjkit init

It asks a few setup questions and never overwrites a file, so it is safe in a repository with code. Useful options: --mode quick, --from ./docs, --provider none.Hace unas preguntas de configuración y nunca sobrescribe un fichero, así que es seguro en un repositorio con código. Opciones útiles: --mode quick, --from ./docs, --provider none.

You sign off every phaseTú apruebas cada fase

Only you run it. “Continue” is never a sign-off, and a phase cannot be approved while an earlier one is open.Solo lo ejecutas tú. «Continúa» nunca es una aprobación, y no se aprueba una fase con otra anterior abierta.

pjkit approve <phase>

Small models for work that needs no judgmentModelos pequeños para lo que no necesita criterio

Tests, an approved provision and saved scripts run in subagents with their own context. Only their short report comes back. None of them can edit files.Los tests, un provision aprobado y los scripts guardados se ejecutan en subagentes con su propio contexto. Solo vuelve su informe corto. Ninguno puede editar ficheros.

Write the same code onceEl mismo código, una sola vez

A hook notes what each piece of code the agent writes uses: imports, calls, commands. It recognises the same job even when the names or the URL change.Un hook apunta qué usa cada trozo de código que escribe el agente: imports, llamadas, comandos. Reconoce el mismo trabajo aunque cambien los nombres o la URL.

The memory stays local, with secrets removed. pjkit actions shows it.La memoria es local y sin secretos. pjkit actions la muestra.

The agent writes the same script for the third time, for example to read a page's title and links.El agente escribe el mismo script por tercera vez, por ejemplo para leer el título y los enlaces de una página.
/pk-automate asks once: save it, not now, or never./pk-automate pregunta una vez: guardarlo, ahora no o nunca.
From then on the agent runs the script instead of writing it:Desde entonces el agente ejecuta el script en vez de escribirlo:
